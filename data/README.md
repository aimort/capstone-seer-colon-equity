# Data folder — intentionally empty

SEER data are NOT stored in this repository and cannot be redistributed,
per the SEER Research Data Use Agreement.

To obtain the data:
1. Request access: https://seer.cancer.gov/data/access.html
2. Install SEER*Stat: https://seer.cancer.gov/seerstat/
3. Run the query in ../seerstat/query_spec.md
4. Export the results into this folder as a .txt file (this folder is git-ignored)
